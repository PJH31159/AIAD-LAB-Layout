# AIAD 연구실 공간 배치 시뮬레이터 v2

`AIAD_연구실_공간배치_시뮬레이터_PRD_최종수정본.md`와 손그림을 반영한 오프라인 정적 웹 앱입니다. 외부 라이브러리, 빌드 도구, 서버가 필요하지 않습니다.

## 실행 방법

1. `index.html`을 최신 Chrome 또는 Edge에서 엽니다.
2. 최초 실행 시 추천안인 **가변형 회의 공간형**이 표시됩니다.
3. 작업은 변경 후 500ms 뒤 브라우저 LocalStorage에 자동 저장됩니다.

## 도면 방향과 편집

- 초기 외곽선·유리벽·출입문 좌표는 기존 세로형 도면을 **반시계 방향 90도** 회전하고 최소 X/Y를 0으로 정규화한 실제 v2 좌표입니다. CSS로 캔버스를 회전하지 않습니다.
- 상단 `↶ 90°`, `↷ 90°` 버튼은 외곽선, 공간, 유리벽, 문, 구조물, 가구의 좌표와 회전각을 함께 변경하며 실행 취소할 수 있습니다.
- `꼭짓점` 모드: 점 드래그, 벽 더블클릭으로 점 추가, Delete로 점 삭제. Shift는 수평·수직 제한, Ctrl/Cmd는 격자 스냅 임시 해제입니다.
- `벽 편집` 모드: 선분 선택 후 길이와 고정 기준(시작점/끝점/중심), 수평·수직 정렬, 분할, 인접 벽 병합을 사용할 수 있습니다.
- 유리벽은 선 또는 끝점 핸들을 드래그할 수 있으며 길이·두께·잠금을 편집할 수 있습니다.
- 공간 라벨 영역을 선택하면 공간 이름과 용도를 변경할 수 있습니다.

## 가구와 배치안

- 대학원생/학부생 책상·의자, 교수 책상 2종, 대형 모니터, 회의 가구, 소파, 냉장고, 수납 및 공용 가구를 독립 객체로 제공합니다.
- 가구를 클릭해 추가한 뒤 드래그합니다. 속성 패널에서 이름, 소속 공간, 좌표, 크기, 회전, 색상, 잠금을 편집할 수 있습니다.
- `학습 중심형`, `회의 중심형`, `가변형 회의 공간형`을 즉시 적용하고 비교할 수 있습니다. 현재안은 이름을 지정해 저장·복제할 수 있습니다.
- Ctrl/Cmd+A는 모든 가구를 선택하고 Delete는 일괄 삭제합니다.

## 분석과 경고

- 면적, 점유율, 좌석, 경고 수와 교수 요구 수량 10종의 현재/목표 및 충족률을 실시간 표시합니다.
- 가구 겹침, 외곽 이탈, 문 열림 영역, 유리벽 안전거리, 냉장고 접근, 모니터 전면 가림, 회의 테이블/학부생 책상 충돌, 자기 교차를 검사합니다.
- 회의 패널에 모니터–회의 테이블 거리, 회의 좌석, 출입구 접근, 냉장고 배치 여부와 빛 반사 현장 확인 안내를 표시합니다.

## 저장과 출력

- JSON 내보내기는 v2 좌표, orientation, 공간, 벽/유리벽, 문/창, 구조물, 가구, 목표 수량과 설정을 포함합니다.
- orientation이 없는 v1 JSON은 원본을 LocalStorage에 백업한 뒤 사용자 동의에 따라 왼쪽으로 90도 회전하여 가져옵니다. 자세한 내용은 `migration-guide.md`를 참고하세요.
- PNG는 1x/2x/4x와 격자 포함 여부를 선택하며 편집 핸들·선택 테두리를 제외합니다.
- PDF 인쇄는 A4 가로 레이아웃을 사용합니다.

## 단축키

- `V` 선택, `N` 꼭짓점, `W` 벽 편집, `M` 거리 측정, `H` 화면 이동
- `Delete` 삭제, `Ctrl/Cmd+D` 복제, `Ctrl/Cmd+A` 전체 가구 선택
- `Ctrl/Cmd+Z` 실행 취소, `Ctrl/Cmd+Shift+Z` 또는 `Ctrl/Cmd+Y` 다시 실행, `Ctrl/Cmd+S` 저장
- 마우스 휠 확대/축소, Space+드래그 또는 중간 버튼으로 화면 이동
