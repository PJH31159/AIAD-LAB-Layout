# AIAD Layout

실측한 연구실 공간과 가구를 `mm` 단위로 배치하는 데스크톱 중심 2D 편집기입니다. React, TypeScript, Vite, SVG, Zustand로 구성되며 별도 서버 없이 GitHub Pages에서 동작합니다.

## 주요 기능

- 불규칙 연구실 외곽과 실제 mm 좌표계
- 실측 너비·깊이 기반의 연구실 공간 크기 설정
- 현재 작업 보관, 보관된 배치안 열기·삭제
- 공간 요소 6종, 가구 7종 클릭·드래그 추가
- 문·창문·콘센트·랜 포트의 공간 외곽 자동 부착
- 책상·수납장·선반·파티션의 50mm 이내 놓기 시 벽 맞춤과 명시적 벽 붙이기
- 선택, 이동, 4방향 크기 조절, 15도 단위 회전
- 검증 가능한 정수 치수 편집, 잠금, 복제, 삭제
- 확대·축소, 패닝, 화면 맞춤, 격자, mm 스냅, 정렬 보조선
- 가구 겹침, 최소 통로 폭, 기둥 충돌, 외곽 이탈 경고와 관련 객체 이동
- 50단계 실행 취소·다시 실행
- localStorage 자동·수동 저장과 저장 중·완료·실패 상태 표시
- v4 JSON 입출력, v3 mm 호환 및 기존 v2 cm 데이터 자동 변환
- 격자·이름·치수·배경 옵션을 적용한 PNG 내보내기
- 좌우 패널 접기와 1024~1920px 데스크톱 반응형 레이아웃
- 자체 호스팅 프리텐다드 WOFF2 기반의 일관된 한글 UI

기술·UX 결정과 기존 기능 이전 범위는 [`DESIGN.md`](./DESIGN.md)에 기록되어 있습니다.

## 실행

Node.js 20.19 이상 또는 22.12 이상이 필요합니다.

```bash
npm install
npm run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 엽니다.

## 검증과 빌드

```bash
npm run lint
npm run test
npm run build
npm run preview
```

정적 결과는 `dist/`에 생성됩니다. Vite `base`가 `./`이므로 저장소 이름과 무관하게 GitHub Pages의 하위 경로에서 자산을 불러옵니다.

## 단축키

- `Delete` / `Backspace`: 선택 객체 삭제
- `Ctrl/Cmd + Z`: 실행 취소
- `Ctrl/Cmd + Shift + Z` 또는 `Ctrl/Cmd + Y`: 다시 실행
- `Ctrl/Cmd + D`: 선택 객체 복제
- `Ctrl/Cmd + C`: 선택 객체 복사
- `Ctrl/Cmd + V`: 복사한 객체 붙여넣기
- `Ctrl/Cmd + S`: 수동 저장
- `Escape`: 진행 중인 이동·크기 조절·회전 취소 또는 선택 해제
- `L`: 잠금 전환
- 방향키: 격자 한 칸 이동
- `Shift + 방향키`: 격자 다섯 칸 이동
- 마우스 휠: 포인터 중심 확대·축소
- 빈 캔버스 드래그: 화면 이동
- `Option/Alt`를 누른 채 가구 놓기: 벽 맞춤 일시 해제

입력 필드를 편집할 때는 객체 단축키가 실행되지 않습니다.

## GitHub Pages 배포

1. GitHub 저장소의 **Settings → Pages**에서 Source를 **GitHub Actions**로 선택합니다.
2. 기본 브랜치에 푸시하면 `.github/workflows/deploy.yml`이 의존성 설치, 테스트, lint, 빌드를 수행합니다.
3. 성공한 `dist/` 아티팩트를 GitHub Pages에 배포합니다.

라우터와 서버 렌더링을 사용하지 않으므로 새로고침 경로 오류가 없습니다.

## 데이터 버전

현재 버전은 `4`이며 모든 치수와 좌표를 mm로 저장합니다. 기존 v3 mm JSON은 현재 배치를 보존하여 불러오고, `2.0.0` JSON은 가져올 때 cm 값을 10배 하여 변환합니다.
