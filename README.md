# AIAD 연구실 플래너 v3.1

`연구실_도면.png`의 실측 구조를 기준으로 가구를 배치하고, 같은 프로젝트 데이터를 2D와 3D에서 확인하는 웹 기반 공간 배치 시뮬레이터입니다.

## 실행

```powershell
python -m http.server 4173
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. 2D 기능은 외부 라이브러리 없이 동작합니다. 3D는 Three.js와 OrbitControls를 CDN에서 불러오므로 최초 로드 시 인터넷 연결이 필요합니다.

## 공식 빈 연구실

- 최초 상태는 이동 가구가 하나도 없는 `빈 연구실`입니다.
- 왼쪽 800cm 외벽, 돌출·오목 형상, 내부 벽, 중앙 유리 파티션, 출입문과 열림 방향, 창문, 기둥, 에어컨, 배전함, 콘센트, LAN과 주요 실측 치수를 벡터 데이터로 관리합니다.
- 공식 구조물은 잠금 상태이며 일반 선택 모드에서는 선택되지 않습니다. `도면 편집` 또는 `벽` 모드에서만 수정·추가할 수 있습니다.
- 콘센트는 파란 점, LAN은 빨간 점, 배전함은 작은 사각형으로만 표시됩니다. Canvas 안에는 해당 텍스트를 표시하지 않고 좌하단 접이식 범례에서 설명합니다.
- `치수 표시` 버튼으로 실측 치수와 벽 길이 표시를 전환합니다.

## 가구 라이브러리

학생·교수 구분 없이 다음 공통 유형만 제공합니다.

- 책상, 의자
- 회의용 테이블, 회의용 의자
- 소파, 캐비닛, 책장
- 이동식 화이트보드, 대형 모니터, 프린터, 냉장고
- 사용자 정의 가구

카드를 클릭하면 Canvas 중앙에 추가되고, 카드에서 Canvas로 드래그하면 놓은 위치에 추가됩니다. 추가 직후 선택되며 이름, X/Y, 가로·세로, 회전, 색상, 잠금을 수정할 수 있습니다.

## 선택과 정렬

- 빈 공간 드래그: 교차한 이동 가구를 영역 선택
- Shift+클릭: 선택 추가/제거
- Ctrl/Cmd+A: 잠기지 않은 모든 가구 선택
- Esc: 선택 해제
- Delete: 선택 삭제
- 다중 선택: 함께 이동·복제·삭제·그룹화
- 정렬: 좌·우·상·하, 가로 중앙, 세로 중앙, 가로/세로 동일 간격

Grid Snap, Object Snap, Wall Snap과 정렬 보조선을 제공합니다. Alt를 누르면 선택 가구와 가까운 가구의 거리를 cm로 표시합니다.

## 공간 분석

분석 서랍은 기본적으로 닫혀 있으며 상단 `공간 분석`으로 엽니다.

- 전체 연구실 면적
- 가구 점유 면적과 점유율
- 남은 사용 가능 면적
- 책상 수와 의자 수
- 전체 좌석과 회의용 좌석
- 근사 최소 통로 폭
- 배치 경고 수

기존 학생별·교수별 목표 수량과 충족률은 제거되었습니다.

## 3D Viewer

- 2D와 동일한 `room` 및 `furniture` 데이터를 사용합니다.
- 실제 Polygon 바닥, 270cm 벽, 투명 유리벽, 문·창, 고정 구조물과 low-poly 가구를 생성합니다.
- 2D의 추가·삭제·이동·회전·크기·벽 변경은 새로고침 없이 3D 전환 시 반영됩니다.
- Perspective, Top, Front, Fit View와 전체 벽/앞 벽 숨김/벽 반투명 옵션을 제공합니다.

## 저장과 배치안

- LocalStorage 자동 저장과 마지막 배치 자동 복원
- 실행 취소/다시 실행 50단계
- JSON 가져오기/내보내기
- PNG 저장과 A4 가로 PDF 인쇄
- `가구 초기화`: 이동 가구만 삭제
- `전체 도면 초기화`: 확인 모달 후 공식 도면과 가구 복원
- 애플리케이션 제공 예제 배치안은 없습니다. 사용자가 이름을 지정해 자신의 배치안을 저장·복제·불러오기·비교할 수 있습니다.

## 데이터 모델

```text
Project
├─ room
│  ├─ boundary
│  ├─ walls
│  ├─ glassWalls
│  ├─ doors
│  ├─ windows
│  └─ fixedFacilities
├─ furniture
├─ layouts
└─ settings
```

기존 JSON의 학생·교수 책상은 `desk`, 학생 의자는 `chair`로 마이그레이션하며 교수 요구 수량 데이터는 제거합니다. 자세한 내용은 `migration-guide.md`를 참고하세요.

## 파일 구조

```text
index.html                       UI 구조
style.css                        기존 공통 스타일
ui.css                           Floorplanner형 UI와 범례
script.js                        2D 편집·저장·분석·마이그레이션
src/data/default-floorplan.js    공식 연구실 구조
src/3d/scene-manager.js          Three.js Viewer
```

## 단축키

- `V` 선택, `N` 도면 편집, `W` 벽 편집, `M` 거리, `H` 화면 이동
- `Ctrl/Cmd+A` 전체 선택, `Ctrl/Cmd+D` 복제
- `Ctrl/Cmd+Z` 실행 취소, `Ctrl/Cmd+Y` 다시 실행, `Ctrl/Cmd+S` 저장
- `Delete` 삭제, `Esc` 선택 해제, `Alt` 거리 표시
- 휠 Zoom, Space+드래그 또는 중간 버튼 Pan
